# Aureka style

The default style follows the owner-supplied `2026-template.pptx` in the AbbVie materials. Its PowerPoint theme was inspected directly, along with the scientific slide layouts. Only the wordmark was extracted. No confidential scientific slide content or source deck is included in this repository.

| Token | Value |
| --- | --- |
| Primary purple | `#6500FF` |
| Deep purple | `#4200AC` |
| Warm yellow | `#F9AC2F` |
| Pink | `#FF6D8E` |
| Mint | `#6FC0A9` |
| Pale pink | `#FFBFDF` |
| Lavender wash | `#F0EAFF` |
| Text | `#333333` |
| Font | Arial |

Scientific figures use a white background, a bold Arial title, restrained accent strokes, and a centered Aureka footer wordmark. Genetic parts retain their SBOL Visual geometry. Colors distinguish roles and do not establish biological function. Exported PowerPoint theme accents match the supplied corporate theme. The original wordmark remains an image with its aspect ratio preserved; construct glyphs and labels remain native editable objects.

The app uses the same palette, typography and wordmark. `Aureka / purple & gold` is the default for new sessions and CLI exports. Existing saved projects retain their selected palette and individual feature colors.

The wordmark is Aureka branding supplied for this project. The software's MIT license does not grant trademark rights or relicense that artwork.
